# Personal Portfolio Website

## Overview

This project is a responsive Personal Portfolio Website developed using HTML5 and CSS3 as part of the Full Stack Development course assignment. The website showcases my personal profile, technical skills, projects, and contact information. The design is simple, clean, and responsive so that it works well on desktop, tablet, and mobile devices.

## Design Rationale

The website follows a modern and minimal design with a consistent color theme for better readability. Semantic HTML elements such as `header`, `nav`, `main`, `section`, `article`, and `footer` are used to improve structure, accessibility, and maintainability. CSS variables are used to manage colors consistently throughout the website.

## Layout Technique

Flexbox is used to create responsive layouts for the navigation bar, hero section, skills, and project cards. Media queries are implemented at 768px and 480px to ensure the website adapts properly to tablet and mobile screen sizes. Hover effects and CSS transitions are added to improve the user experience.

## Accessibility

The website includes proper heading hierarchy, descriptive image alt text, and labels associated with form inputs to improve accessibility and usability.

## Known Limitations

The website is developed using only HTML and CSS. The contact form is static and does not send messages. Interactive features such as dark mode, animations on scroll, and backend functionality will be added in future assignments using JavaScript and Node.js.
